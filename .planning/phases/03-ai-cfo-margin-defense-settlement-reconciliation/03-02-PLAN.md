  <action>
Implement the bill scanning and dual write confirmation endpoints in backend/routers/cfo_router.py per D-02:

1. Implement POST /api/v1/cfo/scan-distributor-bill:
   - Accept either file upload (UploadFile via File(None)) or JSON body with use_demo_sample=True.
   - Read image bytes if file provided (enforce 10MB limit per threat model T-03-01).
   - Invoke bill_parser_service.parse_distributor_bill with the image bytes or demo sample flag, passing SQLite connection.
   - Return structured response matching PRD section 7.2 with status="PROPOSAL", supplier_name, invoice_number, invoice_total, price_creep_alerts, line_items, dual_action_preview, and tts_audio_base64.

2. Implement POST /api/v1/cfo/confirm-distributor-bill:
   - Define Pydantic request model ConfirmBillRequest:
     * invoice_number: str
     * supplier_name: str
     * line_items: list of items with item_id, sku_name, qty, unit_cost, line_total
     * invoice_total: float
     * price_creep_detected: bool = False
     * update_selling_prices: Optional[dict[str, float]] = None
   - Idempotency guard: Query supplier_ledger for invoice_number. If already recorded, return HTTP 200 or 409 with status="ALREADY_CONFIRMED" without duplicating writes.
   - Execute atomic SQLite transaction:
     a. For each line item in line_items:
        - Update inventory_items: increase current_stock by qty, update previous_unit_cost = last_unit_cost, and set last_unit_cost = unit_cost. If update_selling_prices specifies a new selling price for this SKU, update selling_price.
        - Insert row into stock_events: item_id, event_type="INWARD_INVOICE", quantity_delta=qty, unit_cost=unit_cost, invoice_number=invoice_number, raw_transcript=f"Distributor bill confirmation: {invoice_number}".
     b. Insert row into supplier_ledger:
        - supplier_name, entry_type="INVOICE_CREDIT", amount=invoice_total, invoice_number=invoice_number, price_creep_flagged=price_creep_detected.
     c. Insert row into business_events:
        - event_category="CFO_ALERT", summary_text=f"Confirmed distributor bill {invoice_number} from {supplier_name}: +{sum(item['qty'] for item in line_items)} units, Rs {invoice_total:,.2f} added to supplier khata", evidence_json with full bill summary, actor="MERCHANT_APPROVED".
     d. Commit transaction.
   - Return response JSON: status="CONFIRMED", invoice_number, stock_events_created=len(line_items), supplier_ledger_id, business_event_id, and message="Stock and supplier khata updated atomically."

3. Expand tests/test_cfo_router.py with tests for:
   - POST /api/v1/cfo/scan-distributor-bill using use_demo_sample=True returns proposal with Fortune Oil price creep alert (+7.58%).
   - POST /api/v1/cfo/scan-distributor-bill with multipart file upload returns valid proposal.
   - POST /api/v1/cfo/confirm-distributor-bill executes dual atomic writes and updates stock in inventory_items and records payable in supplier_ledger.
   - Repeated confirmation of same invoice_number is rejected or handled idempotently.

## Trust Boundaries

|----------|-------------|
| Client HTTP Requests → AI CFO Router | Untrusted parameters, unconfirmed quantities, or duplicate invoice confirmation submissions |
| Application Router → Database Ledgers | Dual-table state mutation crossing between inventory stock and supplier financial payable |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-04 | Tampering | backend/routers/cfo_router.py | critical | mitigate | Wrap inventory updates, stock_events, supplier_ledger, and business_events in a single atomic SQLite transaction; rollback on any error |
| T-03-05 | Repudiation | backend/routers/cfo_router.py | high | mitigate | Enforce idempotency on invoice_number in supplier_ledger to prevent duplicate stock or financial credit entries |
| T-03-06 | Denial of Service | backend/routers/cfo_router.py | medium | mitigate | Enforce Pydantic validation on request schemas and cap multipart file uploads to 10MB |
| T-03-SC | Tampering | External Python Dependencies | high | mitigate | Rely on built-in FastAPI and SQLite transaction handling; verify dependencies remain unchanged |
