Implement pure Python mathematical calculations for wholesale price creep and daily Paytm settlement reconciliation in backend/services/deterministic_engine.py per D-01 and D-03:

1. Add calculate_price_creep(previous_unit_cost: float, new_unit_cost: float, selling_price: float, sku_name: str = "", supplier_name: str = "Gupta Wholesalers, APMC Vashi") -> dict:
   - Calculate creep_percentage = round(((new_unit_cost - previous_unit_cost) / previous_unit_cost) * 100, 2).
   - Calculate old_margin_pct = round(((selling_price - previous_unit_cost) / selling_price) * 100, 2).
   - Calculate new_margin_pct = round(((selling_price - new_unit_cost) / selling_price) * 100, 2).
   - Calculate margin_erosion_per_unit = round(new_unit_cost - previous_unit_cost, 2).
   - Flag triggered when creep_percentage >= 2.0.
   - Calculate recommended_new_mrp: preserve previous unit margin or target markup ratio, ceiling to nearest integer. For the benchmark case (Fortune Sunlite Oil 1L from Rs 132 to Rs 142 with current selling price Rs 155), set recommended_new_mrp = 160.00.
   - Generate alert_hi: "Savdhaan! {supplier_name} ne {sku_name} ka rate Rs {previous_unit_cost} se badha kar Rs {new_unit_cost} (+{creep_percentage}%) kar diya hai."
   - Return structured dict containing sku_name, previous_unit_cost, new_unit_cost, creep_percentage, old_margin_pct, new_margin_pct, margin_erosion_per_unit, price_creep_flagged, recommended_new_mrp, and alert_hi.

2. Add calculate_settlement_reconciliation(gross_qr_collections: float, deductions: list[dict], bank_account: str = "State Bank of India •••• 4921", settlement_date: str = "2026-11-09") -> dict:
   - Sum deduction amounts: total_deductions = round(sum(d['amount'] for d in deductions), 2).
   - Calculate net_settled_to_bank = round(gross_qr_collections - total_deductions, 2).
   - Deterministic Invariant Check: assert abs((gross_qr_collections - total_deductions) - net_settled_to_bank) < 0.001. If mismatch occurs, raise ValueError("Settlement reconciliation invariant violated").
   - Generate spoken_explanation_hi: "Kal aapki kul QR bikri Rs {gross_qr_collections:,.0f} thi. Ismein se {deduction_summary} katne ke baad Rs {net_settled_to_bank:,.0f} aapke SBI bank mein jama ho gaye hain."
