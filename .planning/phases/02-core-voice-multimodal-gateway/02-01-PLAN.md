<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Backend Service → External Sarvam AI API | Untrusted public internet connection subject to latency spikes, dropped packets, and DNS outages |
| Client Payload → Audio Transcriber | Raw audio byte streams uploaded by browser/mobile device crossing into parsing buffers |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Denial of Service | backend/services/sarvam_engine.py | critical | mitigate | Wrap all external HTTP calls in strict httpx 6.0-second timeout; immediately switch to local synthetic generator on timeout |
| T-02-02 | Information Disclosure | backend/services/sarvam_engine.py | high | mitigate | Read SARVAM_API_KEY from environment variables only; redact keys in log messages and health check responses |
| T-02-03 | Tampering | backend/services/sarvam_engine.py | medium | mitigate | Validate audio byte lengths (max 10MB limit) before processing; discard oversized payloads safely |
| T-02-SC | Tampering | External HTTP / Audio libraries | high | mitigate | Utilize built-in Python standard library wave/struct and vetted httpx dependency; lock package versions |
</threat_model>
