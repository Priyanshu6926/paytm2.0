<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Merchant Voice/Text Input → `/api/v1/voice/propose` & `/confirm` | Ambiguous or misparsed shop commands attempting premature or misattributed ledger writes |
| User File Input (`<input type="file">`) → `/api/v1/cfo/scan-distributor-bill` | Local image file uploads (type/size validation and ObjectURL lifecycle) |
| Proposal Confirm Actions → Financial/Inventory Mutations | Double-tap or accidental confirmation of distributor invoices or UPI reconciliations |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-04 | Tampering / Repudiation | `MunimMicTab.tsx` | high | mitigate | Enforce Propose -> Confirm -> Commit UI gate: `NEEDS_DISAMBIGUATION` and `PROPOSAL` cards never auto-commit; writes require explicit tap on candidate or `Approve (Haan)` sending `action: "APPROVE"` and disable submit buttons while in-flight |
| T-05-05 | Denial of Service (Client File Upload) | `AiCfoTab.tsx` | medium | mitigate | Validate image file size (`<= 10MB`) and MIME type (`image/*`) before calling `scanDistributorBill`, and always call `URL.revokeObjectURL` on preview unmount/replacement to prevent browser memory leaks |
| T-05-06 | Tampering / Replay | `AiCfoTab.tsx` | medium | mitigate | Disable `Confirm & Update Stock + Khata` and UPI resolve buttons during submission (`submitting` state) and handle `"ALREADY_CONFIRMED"` idempotently without surfacing false errors |
| T-05-SC | Tampering | `frontend/package.json` (npm) | high | mitigate | Use only locked dependencies installed and verified in Plan 05-01 with zero unvetted third-party packages |
</threat_model>
