| Boundary | Description |
|----------|-------------|
| Browser File Upload (`<input type="file">`) → `/api/v1/cmo/scan-bahi-khata` | Handwritten notebook image uploads and batch-edited onboarding payloads |
| Judge Demo Quick-Trigger Bar → Live Financial/CMO Endpoints | Repeated stage clicks firing QR webhooks, payment link settlements, or promo clicks |
| Business Events JSON (`evidence_json`) → `MemoryTimelineTab.tsx` | Arbitrary JSON evidence payloads rendered inside audit timeline drawers |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-07 | Tampering / XSS | `AiCmoTab.tsx`, `MemoryTimelineTab.tsx` | high | mitigate | Render all translated messages, Bahi-Khata OCR notes, and `business_events` JSON evidence strictly via escaped React text nodes; sanitize/validate positive finite numeric amounts (`amount > 0`) before calling `confirmBahiKhata` |
| T-05-08 | Denial of Service (File Upload & Rapid Clicks) | `AiCmoTab.tsx`, `JudgeDemoBar.tsx` | medium | mitigate | Validate Bahi-Khata upload size (`<= 10MB`), revoke `ObjectURL` previews on cleanup, and lock active Judge Demo chip / mutation buttons (`inFlight` state) while requests are pending |
