## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Application Service → SQLite Engine | Untrusted query parameters or schema tampering crossing into raw SQL execution |
| External Storage / FS → Database File | Direct file system manipulation or corruption of backend/data/kiranaos.db |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Tampering | backend/database/schema.sql | high | mitigate | Enforce SQLite triggers raising ABORT on UPDATE and DELETE statements on financial and inventory tables |
| T-01-02 | Tampering | backend/database/connection.py | critical | mitigate | Use parameterized SQL bindings exclusively across all queries; prohibit raw string interpolation |
| T-01-03 | Denial of Service | backend/data/kiranaos.db | medium | mitigate | Enable SQLite WAL (Write-Ahead-Logging) mode and 5000ms busy timeout to prevent database lock contention |
| T-01-SC | Tampering | Python sqlite3 / standard library | high | mitigate | Rely on Python 3 standard library sqlite3 module; zero external unvetted database driver dependencies |
</threat_model>
